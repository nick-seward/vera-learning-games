# Vera's Learning Games

A small collection of kid-friendly, single-page learning games, hosted with GitHub Pages and designed to work well on iPad Safari.

- **Word Search (Week 5)** – `word-search-week5/`
- **Word Search (Week 6)** – `word-search-week6/` (prefix dis- and il/al words)
- **Word Search (Week 7)** – `word-search-week7/` (-er/-est suffixes and long-i -ile words)
- **Times Tables** – `times-tables/`
- **Canada Capitals** – `canada-capitals/`
- **Canada Map** – `canada-map/` (find and name the provinces & territories on a map; map data from Natural Earth, public domain)
- **Bar Models** – `bar-models/` (multi-step word problems solved with bar models / tape diagrams: whole minus parts, equal groups then total, and find-one-then-many rates; Learn and Challenge modes)
- **Spell It to Save It (Week 7)** – `spell-it-week7/` (wizard-themed spelling game: hear the word and a sentence, spell it on big letter keys to light candles; Easy/Normal modes, 10-word rounds or all 20, tricky-words review saved on the device. To reuse for a new week, copy the folder and swap the `WORDS` array at the top of the script)

Open the home page (`index.html`) and tap a card to play. Everything is plain static HTML, CSS, and JavaScript; there's no build step.
